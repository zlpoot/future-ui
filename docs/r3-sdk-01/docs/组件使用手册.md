# 组件使用手册（@future-ui/shadcn-adapter/browser）

本文档依据 SDK 实际打包的 TypeScript 类型声明（`packages/future-ui-shadcn-adapter-0.1.0-rc.1.tgz`
内的 `dist/components/*.d.ts`）与真实 Profile 编写。所有示例与模板 demo 一致，可直接运行。

## 0. 导入方式（唯一合法入口）

组件只允许从 **Browser 入口**导入：

```tsx
import {
  EditDialog,
  ShadcnButton,
  ShadcnTextInput,
  editDialogProfile,
} from '@future-ui/shadcn-adapter/browser';
import type {
  EditDialogProps,
  EditDialogField,
  EditDialogOpenChangeDetail,
  ShadcnButtonProps,
  ShadcnTextInputProps,
  ShadcnTextInputValueChangeEvent,
} from '@future-ui/shadcn-adapter/browser';
```

**禁止**从 `@future-ui/shadcn-adapter` 根入口导入：根入口会再导出 Node-only 校验器
（传递依赖 `node:fs`），会破坏浏览器/Vite 构建图。

## 1. ShadcnButton

薄封装 over vendored shadcn Button，补齐冻结契约要求的缺口（loading → aria-busy + disabled + 不触发 click）。

```tsx
interface ShadcnButtonProps {
  disabled?: boolean;
  loading?: boolean;            // loading=true 时按钮 aria-busy、disabled、不发出 click
  type?: 'button' | 'submit' | 'reset';   // 契约默认 'button'
  variant?: 'default' | 'destructive' | 'outline' | 'secondary' | 'ghost' | 'link';
  size?: 'default' | 'sm' | 'lg' | 'icon';
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;
  children?: React.ReactNode;
  className?: string;
  'aria-label'?: string;
  'data-testid'?: string;
}
```

示例：

```tsx
<ShadcnButton type="button" variant="outline" size="sm" data-testid="edit-item"
  onClick={() => setEditing(item)}>
  编辑
</ShadcnButton>

{/* pending 场景：loading 态由业务状态驱动 */}
<ShadcnButton type="button" loading={saving} onClick={handleSave}>
  保存
</ShadcnButton>
```

## 2. ShadcnTextInput

薄封装 over vendored shadcn Input。契约要点：

- `onValueChange` 载荷是 `{ value: string }`，**不是裸字符串**；程序化设置 value 不触发该事件。
- `name` 同时映射为原生 `name` 与 `aria-label`（契约可访问性条款）。
- `error` → `aria-invalid`；`description` → `aria-describedby` + 可见说明。

```tsx
interface ShadcnTextInputProps {
  value?: string;
  defaultValue?: string;
  disabled?: boolean;
  readOnly?: boolean;
  error?: boolean;
  name?: string;
  description?: string;
  placeholder?: string;
  type?: 'text' | 'email' | 'password' | 'number' | 'search' | 'tel' | 'url';
  autoComplete?: string;
  onValueChange?: (event: ShadcnTextInputValueChangeEvent) => void;
  className?: string;
  id?: string;
}
```

示例：

```tsx
<ShadcnTextInput
  id="member-search"
  name="member-search"          // name → aria-label，测试可用 getByLabelText('member-search')
  placeholder="搜索成员…"
  value={keyword}
  onValueChange={(e) => setKeyword(e.value)}
  className="w-full"
/>

<ShadcnTextInput
  name="email"
  label="邮箱"
  placeholder="name@example.com"
  error={invalid}
  description={invalid ? '邮箱格式不正确' : undefined}
/>
```

> 注意：`ShadcnTextInput` 的 props 是 `name`（映射 aria-label），**没有 `label` prop**；
> 需要可见标签时用原生 `<label htmlFor>` 包住。

## 3. EditDialog

组合式编辑对话框（vendored shadcn Dialog/Button/Input + Project Profile）。**Host 拥有 open 状态**：
组件自身不改变业务状态；关闭原因通过 `onOpenChange(detail)` 回传。

```tsx
interface EditDialogField {
  name: string;
  label: string;
  value?: string;          // 受控初值（打开时生效）
  defaultValue?: string;
  placeholder?: string;
  type?: ShadcnInputType;
  description?: string;
  error?: boolean;
  autoComplete?: string;
}

type EditDialogCloseReason = 'save' | 'cancel' | 'x' | 'discard' | 'pending-confirm';

interface EditDialogOpenChangeDetail {
  open: boolean;
  reason: EditDialogCloseReason;   // 仅在 open=false 时有意义
}

interface EditDialogProps {
  open: boolean;
  onOpenChange: (detail: EditDialogOpenChangeDetail) => void;
  label: string;                    // 可访问名称（渲染为 DialogTitle）
  description?: string;
  fields: EditDialogField[];
  onSave: (values: Record<string, string>) => Promise<void> | void;
  blocking?: boolean;               // 阻塞变体：移除普通取消与 X，仅 save/discard 可关闭
  profile?: ProjectProfile;         // 默认 R1 Profile
  className?: string;
}
```

### 3.1 基本用法（编辑预填 + 保存 + 取消不保存）

```tsx
const [editing, setEditing] = useState<Item | null>(null);

const fields = editing
  ? [
      { name: 'title', label: '标题', value: editing.title },
      { name: 'description', label: '描述', value: editing.description },
    ]
  : [];

const handleSave = async (values: Record<string, string>) => {
  const target = editing;
  if (!target) return;
  await delay(500); // 模拟保存；pending 中间态由 EditDialog 呈现
  setItems((prev) => prev.map((item) =>
    item.id === target.id
      ? { ...item, title: values.title ?? item.title }
      : item));
};

const handleOpenChange = (detail: EditDialogOpenChangeDetail) => {
  if (!detail.open) setEditing(null); // 取消/X/保存完成 均走到这里
};

<EditDialog
  open={editing !== null}
  profile={editDialogProfile}
  label="编辑条目"
  description="预填、取消不保存；保存 pending 后自动关闭并更新列表"
  fields={fields}
  onSave={handleSave}
  onOpenChange={handleOpenChange}
/>
```

### 3.2 行为契约（务必遵守，避免与冻结行为冲突）

| 行为 | 说明 |
|---|---|
| 打开 | `open=true` 时按 `fields` 预填（value/defaultValue 在打开时生效）；打开时初始焦点落在第一个字段 |
| 保存 pending | `onSave` 返回 Promise 期间，保存按钮显示“保存中…”并 disabled，**阻止重复提交**；完成后自动关闭，`reason='save'` |
| 取消 | 点击“取消”→ 关闭且 `reason='cancel'`；业务列表保持不变（Host 负责不写入） |
| X 按钮 | 点击右上角 X → 关闭且 `reason='x'` |
| **Esc** | **按 Esc 不会关闭 Dialog**（契约 R1-DLG-02：Esc/遮罩被 `preventDefault`，不允许成为唯一关闭途径）；请通过取消/X/保存关闭 |
| 遮罩点击 | 点击 Dialog 外遮罩不会关闭（同样被 `preventDefault`） |
| blocking | 传 `blocking` 时移除普通取消与 X，仅 save / discard 可关闭（异常路径 EX-BLK-001） |
| 受控 | Host 持有 `open`；组件从不自行改动状态，`onOpenChange(false)` 后由 Host 决定是否清空编辑态 |

### 3.3 pending 与防重复（参考 fixture 写法）

```tsx
// src/fixture.test.tsx 可验证：保存点击 → “保存中…” disabled → resolve 后自动关闭
await user.click(screen.getByRole('button', { name: '保存并关闭' }));
expect(screen.getByRole('button', { name: '保存中…' })).toBeDisabled();
await screen.findByRole('button', { name: '保存并关闭' }); // pending 结束恢复
```

## 4. 支持边界（真实 Profile，来自 `editDialogProfile` / D15 映射）

| 组件 | 状态 | 说明 |
|---|---|---|
| EditDialog | **supported** | 预填/取消/pending/防重复/关闭语义全部映射无 unsupported 成员 |
| ShadcnButton | **partial** | 契约 `features.loading` 标记 unsupported（适配器以 composition 实现 aria-busy+disabled，但仍按 partial 如实标注） |
| ShadcnTextInput | **partial** | 契约 `accessibility.role` 等成员 unsupported；`name→aria-label` 已实现 |

> `ai:view` 会输出每个组件的 `mapping.domains` 逐条结论（supported / partial / unsupported / not-covered），
> 以 JSON 为准，不要臆断。

## 5. 常见错误

| 错误 | 原因与修复 |
|---|---|
| 从根入口 `@future-ui/shadcn-adapter` 导入报 `node:fs` 相关错误 | 必须改用 `/browser` 入口 |
| `aria-label` 传给 ShadcnTextInput 不生效/类型报错 | 该组件无 `aria-label` prop；用 `name`（自动映射 aria-label） |
| 按 Esc 后 Dialog 未关闭 | 这是契约行为，不是 bug；用取消/X/保存关闭 |
| `onValueChange` 收到裸字符串 | 载荷是 `{ value }` 对象；取 `event.value` |
